# 🤖 Machine Learning Projects

Welcome to my **Machine Learning Projects** repository! This collection
showcases practical machine learning projects covering **regression,
classification, dimensionality reduction, data preprocessing, exploratory
data analysis, model building, and evaluation**.

Each project is implemented using **Python and Jupyter Notebook**, with a
focus on understanding machine learning concepts through hands-on practice.

---

## 📁 Project Overview

### 1. 🚗 Car MPG Prediction Using Linear Regression

- **Objective:** Predict vehicle fuel efficiency (`mpg`) using automobile-related features.
- **Techniques:** Data Preprocessing, Exploratory Data Analysis, Linear Regression, Polynomial Features.
- **Highlights:** Cleans and preprocesses the Car MPG dataset, explores relationships between features, builds a regression model, and evaluates its performance.

### 2. 🩺 Diabetes Prediction Using Logistic Regression

- **Objective:** Predict whether a person has diabetes based on the features provided in the Pima Indians Diabetes dataset.
- **Techniques:** Data Preprocessing, Exploratory Data Analysis, Logistic Regression, Feature Scaling, Confusion Matrix.
- **Highlights:** Performs data analysis and preprocessing, builds a binary classification model, evaluates predictions, and examines classification errors using a confusion matrix.

> **Note:** This project is for educational purposes and should not be used as a medical diagnostic system.

### 3. 📉 Principal Component Analysis (PCA) on Car MPG

- **Objective:** Explore dimensionality reduction using Principal Component Analysis on the Car MPG dataset.
- **Techniques:** Data Preprocessing, Standardization, Covariance Matrix, Eigenvalues, Eigenvectors, PCA, Explained Variance.
- **Highlights:** Analyzes the feature space, calculates principal components, studies explained variance, reduces dimensionality, and explores the effect of PCA on regression.

## 🚀 Getting Started

To explore and run these projects locally:

1. Clone the Repository
git clone https://github.com/anjsake71-collab/Machine-learning-projects.git

Navigate to the project directory:

cd Machine-learning-projects
2. Create a Virtual Environment
Windows
python -m venv .venv

Activate the environment:

.venv\Scripts\activate
macOS / Linux
python3 -m venv .venv

Activate the environment:

source .venv/bin/activate
3. Install Required Libraries
pip install numpy pandas matplotlib seaborn scikit-learn scipy jupyter
4. Start Jupyter Notebook
jupyter notebook
